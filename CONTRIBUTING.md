# Contributing

Every change starts from an issue; see `CLAUDE.md` for the commands and the tests, and [`docs/values.md`](docs/values.md) for what a change is judged against.

The notefeed server is licensed under the AGPL-3.0, and notefeed.me, the hosted instance, sells licenses, so the maintainer must be able to license every line. **A pull request from outside is merged only after its author accepts the [contributor licence agreement](CLA.md)** (a comment on the pull request; it is the standard Apache one, with the Maintainer as the party). The client packages (`packages/js`, `packages/python`) are Apache-2.0, and a client, integration or skill in your own repository needs no agreement.
